1. עזור לי להתכונן ליום שלי M365 Copilot

התדריך שחוסך לך את פתיחת היומן, המייל וה-Teams בבוקר. הכי רלוונטי ליום עבודה עמוס בפגישות ולקוחות.

  1. פתח את Teams ואפליקציית Copilot.
  2. עבור ללשונית Prompts ובחר את התבנית עזור לי להתכונן ליום שלי.
  3. קבע ימי חול בשעה 08:00.
  4. שמור. מחר בבוקר התדריך מגיע לבד לצ׳אט של Copilot.
תדירות: יומי 08:00מקורות: יומן, מייל, משימות, Teams

2. התכונן לפגישות שלי מחר M365 Copilot

תדרוך ערב לקראת כל פגישה של מחר עם קשר למיילים, למסמכים ולדיוני עבר. חוסך את הכנת הרקע לפני כל שיחת לקוח.

  1. Teams, אפליקציית Copilot, לשונית Prompts.
  2. בחר את התבנית התכונן לפגישות שלי מחר.
  3. קבע 20:30 בכל יום.
  4. שמור.
תדירות: יומי בערבמקורות: יומן, מייל, SharePoint, Teams

3. שלח הנחיה מתוזמנת ל-Copilot M365 Copilot

התבנית הגמישה: כל פרומפט שתגדיר, בתזמון קבוע. דוגמאות שכדאי לך: סיכום שבועי של התקדמות מול יעדים, סיכום יום שישי לקראת שבוע חדש.

  1. Teams, אפליקציית Copilot.
  2. לחץ על סמל השעון ליד תיבת ההנחיה.
  3. הזן פרומפט חופשי, למשל: סכם לי את השבוע מול המשימות הפתוחות ואת מה שהתקדם מול לקוחות.
  4. בחר תדירות, למשל יום חמישי 16:00, ושמור.

סיכום שבועי של ערוצים עמוסים שלא קראת, רק של מה שיש לך הרשאה לראות.

5. קבל הודעה כאשר מילת מפתח מוזכרת חינם

התראה פרטית כשמזכירים מילת מפתח בערוצים שבחרת, גם בערוצים עמוסים שלא מספיק לעקוב אחריהם.

  1. פתח את אפליקציית Workflows ב-Teams.
  2. חפש את התבנית קבל הודעה כאשר מילה מפתח מוזכרת.
  3. הזן מילת מפתח, בחר ערוצים ואופן ההתראה, ולחץ Create flow.
תנאי: אפליקציית Workflows מורשית בטננט

6. שלח לערוץ התראות webhook חינם

מחבר את GitHub וכלים חיצוניים לערוץ טכני שלך. המחליף הרשמי של Incoming Webhooks שיצאו משימוש. מי שמחזיק בכתובת יכול לפרסם, אז לשמור אותה בסוד.

  1. אפליקציית Workflows ב-Teams.
  2. חפש שלח לערוץ התראות webhook, תן שם ובחר ערוץ.
  3. לחץ Create flow והעתק את כתובת ה-HTTP POST שהופקה.
  4. הדבק את הכתובת ב-GitHub או בכלי החיצוני.
מתאים ל: GitHub, ניטור, סקריפטים

7. פרסם הודעת ערוץ כאשר פורסם RSS חדש חינם

זרימת עדכונים שוטפת מבלוגים של מיקרוסופט, חדשות AI וכל מקור עם פיד, ישר לערוץ עניין.

  1. אפליקציית Workflows ב-Teams.
  2. חפש פרסם הודעת ערוץ כאשר פורסם RSS חדש.
  3. הזן כתובת פיד RSS ובחר ערוץ יעד.
  4. לחץ Create flow.
תנאי: הפיד נגיש בציבור

  2. אישור חיבור ל-Planner ול-Teams.
  3. בחירת Group ו-Plan, וערוץ היעד ב-Teams.
  4. Create flow.
