# בחירת פריטי Frontier בפורטל הרישוי

המסך בפורטל הרישוי פועל כולו בדפדפן. הוא קורא רק את `frontier-public-index.json`, שנוצר מהעמוד הציבורי של [כנס Frontier](https://guycoful.github.io/microsoft-frontier-2026/). אין בריפו קובצי כספת, תצורת רישוי ארגונית, קוד גישה או כתובת API לשרת. הבחירות בשדות הרישוי אינן נשלחות או נשמרות.

המבקר מזין תפקיד, צוות או נושא. `frontier-public.js` מדרג מקטעים ציבוריים לפי התאמה מילולית והקשרים תפקידיים, מחזיר עד 5, ומציג משפטים שנשלפו מן המקור וקישור למושב. המצב הרישויי הוא בדיקה ראשונית על סמך פרופיל שהמבקר בוחר בדפדפן. כשזמינות או דרישת מוצר אינן ברורות, התוצאה מסומנת לבדיקה; אין לראות בה קביעת זכאות של Microsoft.

`build-frontier-index.py` קורא כתובת ציבורית קבועה בלבד, וסורק את מקטעי 7 המושבים. מקטע חדש עם כותרת ופסקה נכנס לאינדקס בלי להוסיף כלל עבורו. `.github/workflows/frontier-public-index.yml` בודק את המקור מדי יום, מעדכן את קובץ האינדקס רק אם המקור השתנה, ומבקש בנייה מחדש של GitHub Pages. אפשר להפעיל אותו ידנית בלשונית Actions. בדיקות הקבלה `python tools/test-frontier-public.py` ו־`node tools/test-frontier-public.cjs` מוודאות שמקטע חדש נכנס לאינדקס ומופיע בבחירה.

ה־CLI הפרטי על שרת הכספת נפרד מהפורטל הזה וממשיך לפעול בשרת בלבד.
