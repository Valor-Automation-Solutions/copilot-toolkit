# Copilot toolkit for AI leaders

Interactive tools, departmental demo kits, Copilot Studio agents and Office skills,
built by Valor Automation Solutions for Microsoft 365 Copilot adoption.

Live site: https://valor-automation-solutions.github.io/copilot-toolkit/

## What is here

| Path | What it is |
| --- | --- |
| `tools/licensing-app.html` | Licensing portal: decision map, department navigator, capability matrix, over-exposure checklist |
| `tools/prompt-lab.html` | Prompt library organised by role and task, copy to clipboard |
| `tools/cost-calculator.html` | Provider cost comparison; Cowork and Copilot Studio stay on separate lines and are never summed |
| `tools/skill-to-studio.html` | Pipeline that splits a SKILL.md into behaviour, knowledge sources and deterministic actions |
| `tools/training-simulator.html` | Practice environment for end users ahead of the foundations workshop |
| `tools/lecture-deck.html` | Interactive deck for the Copilot lecture |
| `demo-kits/` | Four departmental kits: finance, procurement, logistics, HR |
| `agents/` | Four Copilot Studio agent packages, one per department |
| `skills/` | Seven PowerPoint and Excel skills plus a one-command installer |

Everything runs in the browser with no install. All demo data is synthetic and
created for training purposes only.
