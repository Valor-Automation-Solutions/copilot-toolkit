## מבנה הסדנה (עינת — דקות 61–69)

- פתיחה ~10 דקות: מטרות, אג׳נדה, מה מקבלים, גבולות ברמת משתמש (בלי תמחור עמוק)
- לכל כלי: **יכולות → מגבלות** (כולל מגבלות רישוי רלוונטיות לעובדים) → **דוגמה משותפת**
- לפני כל הדגמה: שקף שלבים 1–4, ואז עושים ביחד
- הדגמות קצרות ≤10 דקות: Excel, Word, PowerPoint, Teams, Email + חיפוש OneDrive/SharePoint (פרימיום — מראים יכולת, אומרים שלא לכולם יש רישיון)
- ~20 דקות מקרים אישיים בסוף (חלק מזמן תרגול מצטבר)
- סגירה: להישאר מעודכנים + יצירת קשר
- תמחור / מכסות / שדרוגים / הטמעה = מסלול נפרד למובילי AI
